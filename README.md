# PolyField AM02i — Interactive Manual

A self-contained, click-through trainer for the PolyField **AM02i** integrated
total station running in **Demo mode** — for online training with no hardware
required.

It walks through the real workflow using the app's own symbols, Material
icons and calibration diagrams:

1. **Select event** — Shot, Discus, Hammer or Javelin (with the real circle radii)
2. **Set Centre** and **Verify Edge** — calibration with simulated readings
3. **Compete** — `MEASURE` / `X` (foul) / `P` (pass), running order and rounds
4. **Standings** — ranked by best mark

Simulated marks are generated on the spot and are not real results.
